# Интеграция модуля "Учет выдачи учебников"
Выполнил: Старков Иван Алексеевич, СИ133

В период прохождения практики в МБОУ Красногорская СОШ передо мной была поставлена задача разработать требования для интеграции простого программного модуля на языке Python. 
Объектом интеграции выступил модуль "Учет выдачи учебников", данный репозиторий/приложение на python - это готовый модуль, который должен быть встроен в существующую школьную систему.
